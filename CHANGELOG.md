## [1.0.0] — 2026-11-18

### Initial public release by SPManchester Private Limited

### Added

- **WebP → PNG** converter — lossless conversion with full transparency support
- **WebP → JPG** converter — high-quality JPEG output with configurable compression
- **WebP → BMP** converter — uncompressed bitmap export for maximum compatibility
- **WebP → ICO** converter — icon generation suitable for favicons and app icons
- **WebP → PDF** converter — single-page PDF embedding for document workflows
- **WebP → SVG** converter — vector-wrapped output for scalable use cases
- **WebP → Base64** converter — inline data-URI encoding for embedding in HTML/CSS
- **Batch processing** — convert multiple WebP files simultaneously in a single session
- **Drag & drop interface** — intuitive file intake via drag and drop or file picker
- **ZIP download** — bulk-export all converted files as a single ZIP archive
- **Privacy-first architecture** — zero backend, zero file uploads; all conversions run entirely in the browser
- **Responsive UI** — fully adaptive layout optimised for both mobile and desktop viewports
