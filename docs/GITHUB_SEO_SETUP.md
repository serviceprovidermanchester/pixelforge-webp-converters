## 5. Social Preview Image

**Location:** Settings → Social preview → Upload an image

| Property | Value |
|----------|-------|
| Dimensions | **1280 × 640 px** |
| Background | Dark (e.g. `#0d1117` or brand dark) |
| Primary content | PixelForge logo (centred or left-aligned) |
| Headline text | **"7 Free WEBP Converters"** |
| Sub-text | `webp-to-png · jpg · bmp · ico · pdf · svg · base64` |
| Footer | `spmanchester.com · Open Source` |

> This image is used when the repository URL is shared on Twitter/X, LinkedIn, Slack, Discord, etc. A clear, high-contrast design maximises click-through rate.

## 6. Repository Settings Checklist

Navigate to **Settings → General → Features** and apply the following:

| Feature | Recommended State |
|---------|------------------|
| ✅ Issues | **On** — bug reports & feature requests |
| ✅ Projects | **On** — roadmap & task tracking |
| ❌ Wiki | **Off** — docs live in `/docs` folder |
| ✅ Discussions | **On** — community Q&A |
| ✅ Sponsorships | **On** — enable GitHub Sponsors button |

## 8. Additional SEO Tips

- **Keep the description updated** whenever a new converter is added.
- **Pin this repository** to your organisation profile (`SPManchester`) so it appears at the top of the org page.
- **Link back** from `https://www.spmanchester.com` to the GitHub repository to build domain authority.
- **Release tags** (`v1.0.0`, `v1.1.0`, …) are indexed by GitHub and appear in search; tag every meaningful release.
- **Alt text** in `README.md` images improves accessibility and is indexed by GitHub search.
